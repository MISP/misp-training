# Editable data-model diagram

The usage deck inputs the [full introduction's TikZ geometry](../../0-misp-introduction-to-information-sharing/diagrams/data-model.tikz) directly, using the [shared style](../../0-intro-shorter/diagrams/style.tex).
Edit geometry there, or the four translated labels in [English](labels-en.tex),
[Spanish](labels-es.tex) and [Dutch](labels-nl.tex) here. Both introduction course
directories must be present; no precompiled diagram is required.

See the [diagram editing/export guide](../../0-misp-introduction-to-information-sharing/diagrams/README.md).
This is a simplified conceptual diagram. The UI examples in the deck are actual
screenshots and are documented separately in the [capture reference](../screenshots/README.md).
